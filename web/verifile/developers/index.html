Für Entwickler und KI-Agenten

Verifile in eigene Programme einbauen.

Alles, was die Verifile-Seite kann, gibt es auch als REST-API und als MCP-Server für KI-Agenten: den Fingerabdruck einer Datei in der Doichain verankern und später prüfen. Ohne Konto und ohne Anmeldung.

Kein Konto nötig

Prüfen ist frei. Verankern geht ohne Schlüssel innerhalb eines Tageskontingents.

Die Datei bleibt bei Ihnen

An den Server geht nur der SHA-256, 64 Zeichen. Datei-Uploads gibt es hier bewusst nicht.

Zwei Wege

Die API für eigenen Code, der MCP-Server für Claude, ChatGPT, Cursor und andere Agenten.

REST-API

Basis-Adresse https://verifile.it/api

Antworten sind JSON. Fehler kommen einheitlich als {"error": {"type": "…", "code": n, "message": "…"}}. Aufrufe aus dem Browser sind von jeder Seite aus erlaubt (CORS).

1. Fingerabdruck berechnen

Der SHA-256 entsteht auf Ihrem Rechner. Jedes geänderte Bit ergibt einen anderen Wert.

sha256sum vertrag.pdf        # macOS: shasum -a 256 vertrag.pdf
(Get-FileHash vertrag.pdf -Algorithm SHA256).Hash.ToLower()

2. Nachweis prüfen

curl https://verifile.it/api/v1/poe/<sha256>

    "explorer_tx": "https://doi-explorer.le-space.de/tx/0a222ff5…"
  }
}
statusBedeutung
unknownFür diesen Hash gibt es keinen Eintrag.
pendingDie Transaktion wartet auf den nächsten Block, im Mittel zehn Minuten.
confirmedVerankert. Das Dokument existierte spätestens zur Blockzeit in first_anchored.
expiredDer Name ist abgelaufen, der Nachweis in first_anchored bleibt gültig.

Maßgeblich ist immer first_anchored, die erste Verankerung. Die Felder auf oberster Ebene beschreiben den heutigen Zustand des Namens und können nach einem Ablauf von einer späteren Registrierung stammen.

3. Nachweis anlegen

curl -X POST https://verifile.it/api/v1/poe/public \
  -H "Content-Type: application/json" \
  -d '{"hash": "<sha256>", "note": "Vertrag Version 3"}'

Antwort 201 mit txid, status: pending und dem verbleibenden Kontingent in quota. note (bis 160 Zeichen) und filename (bis 80 Zeichen) sind freiwillig und danach für immer öffentlich. Ist der Hash schon verankert, kommt 409 und es entsteht kein zweiter Eintrag. Endgültig ist der Nachweis mit dem nächsten Block, danach liefert die Prüfabfrage Blockhöhe und Zeit.

Python

import hashlib
import requests

API = "https://verifile.it/api/v1"

def sha256_of(path):
    digest = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            digest.update(chunk)
    return digest.hexdigest()

h = sha256_of("vertrag.pdf")
proof = requests.get(f"{API}/poe/{h}", timeout=30).json()
if proof["status"] == "unknown":
    r = requests.post(f"{API}/poe/public", json={"hash": h, "note": "Vertrag Version 3"}, timeout=60)
    r.raise_for_status()
    print("anchored, txid", r.json()["txid"])
else:
    first = proof.get("first_anchored") or {}
    print(proof["status"], first.get("block_time_iso"))

JavaScript

const API = "https://verifile.it/api/v1";

async function sha256Hex(buffer) {
  const digest = await crypto.subtle.digest("SHA-256", buffer);
  return [...new Uint8Array(digest)].map((b) => b.toString(16).padStart(2, "0")).join("");
}

const file = document.querySelector("input[type=file]").files[0];
const hash = await sha256Hex(await file.arrayBuffer());
const proof = await (await fetch(`${API}/poe/${hash}`)).json();
console.log(proof.status, proof.first_anchored?.block_time_iso);

Einen Nachweis verlinken Sie mit https://verifile.it/#<sha256>. Die Seite zeigt ihn dann fertig an, auch wenn er über die API entstanden ist.

MCP-Server für KI-Agenten

Adresse https://verifile.it/mcp

Das Model Context Protocol ist der offene Standard, über den KI-Anwendungen externe Werkzeuge einbinden. Einmal eingetragen, entscheidet der Agent selbst, wann er welches Werkzeug nutzt. Sie sagen ihm einfach, was Sie wollen. Transport Streamable HTTP, keine Anmeldung.

WerkzeugWofür
anchor_proofHash eines Dokuments verankern. Ist er schon verankert, kommt der bestehende Nachweis zurück.
check_proofIst der Hash verankert, seit wann und in welchem Block.
hash_textSHA-256 eines kurzen Textes, um Aussagen oder Nachrichten zu verankern. Dateien hasht der Agent selbst auf Ihrem Rechner.
get_anchoring_quotaVerbleibende Nachweise des Tages.

Was Sie dann sagen können

  • „Verankere den Hash von angebot.pdf in der Doichain.“
  • „Prüfe, ob diese Datei schon verankert ist, und seit wann.“
  • „Verankere diesen Text als Nachweis: …“

Ein Agent mit Dateizugriff (Claude Code, Cursor, VS Code) berechnet den Hash selbst. Im reinen Chat ohne Dateizugriff ziehen Sie die Datei auf verifile.it und geben dem Agenten den Hash.

Grenzen und Regeln

Wie viele Nachweise sind frei?

Über die API ohne Schlüssel 3 je Tag und IP-Adresse, über den MCP-Server 10 je Tag und IP-Adresse. Beide Wege zählen getrennt. Dazu gibt es je Weg eine Tagesgrenze für alle zusammen. Der Tag wechselt um 00:00 UTC. Nutzer gehosteter Chat-Apps teilen sich das Kontingent der Server ihres Anbieters. Prüfen ist nicht begrenzt, nur gedrosselt auf 10 Anfragen je Sekunde.

Ich brauche mehr. Was dann?

Auf Anfrage vergibt DOI Labs einen eigenen Schlüssel mit eigenem Tageskontingent. Er wird im Header X-API-Key mitgeschickt, bei der API an POST /v1/poe, beim MCP-Server als Header des Konnektors. Die Kontaktadresse steht im Impressum.

Was wird öffentlich?

Der Hash, die Notiz und der Dateiname, wenn Sie sie mitschicken. Alle drei stehen danach dauerhaft und für jeden lesbar in der Doichain. Schreiben Sie deshalb nie personenbezogene Daten oder Geheimnisse hinein. Aus dem Hash lässt sich die Datei nicht zurückrechnen.

Was beweist ein Nachweis und was nicht?

Er zeigt, dass ein Dokument mit genau diesem Hash spätestens zur Blockzeit existierte. Er zeigt nicht, wer es eingereicht hat. Die Einträge gehören dem Wallet von DOI Labs, das die Gebühr bezahlt.

Wie lange gilt ein Nachweis?

Der Zeitstempel bleibt dauerhaft in der Kettenhistorie. Der Name des Eintrags ist 36.000 Blöcke aktiv, das sind rund 250 Tage. Danach könnte ihn jemand neu registrieren. Deshalb nennt die API in first_anchored immer die erste Verankerung. Ein abgelaufener Hash wird nur dann erneut registriert, wenn Sie das ausdrücklich verlangen.

Was, wenn gerade nichts verankert werden kann?

Fällt das Betriebsguthaben unter eine Reserve, pausiert das Verankern und die API antwortet mit 503. Prüfen geht immer. Ein fehlgeschlagener Versuch kostet kein Kontingent.

Verifile ist der Nachweis-Ausschnitt der Doichain API. Dort gibt es zusätzlich Namen, Blöcke, Transaktionen und Adressen, eine Oberfläche zum Ausprobieren unter /docs und den Doichain MCP-Server mit allen 13 Werkzeugen.
