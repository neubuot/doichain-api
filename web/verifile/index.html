So funktioniert es

1

Fingerabdruck im Browser

Aus Ihrer Datei berechnet der Browser einen SHA-256-Hash, 64 Zeichen, die nur zu genau dieser Datei passen. Ein einziges geändertes Bit ergibt einen anderen Hash.

2

Verankerung in der Doichain

Der Hash wird als Name in der Doichain registriert. Der Block, der ihn enthält, trägt einen Zeitstempel, den niemand nachträglich ändern kann.

3

Nachweis für jeden

Wer die Datei besitzt, berechnet den Hash erneut und findet den Eintrag samt Blockzeit. Dazu genügt diese Seite oder jeder Doichain-Explorer.

Nachweis prüfen

FAQ

Wird meine Datei hochgeladen?

Nein. Der Hash wird mit der Web-Crypto-Funktion Ihres Browsers berechnet. Nur die 64 Zeichen des Hashes werden an den Doichain-Server übertragen. Aus dem Hash lässt sich die Datei nicht rekonstruieren.

Was kostet das?

Für Sie nichts. Die Doichain-Gebühr und das Namenspfand trägt DOI Labs. Damit das so bleibt, gibt es ein Tageskontingent je Nutzer.

Wann ist der Nachweis gültig?

Nach der ersten Bestätigung, im Mittel etwa zehn Minuten nach dem Verankern. Die Seite zeigt den Stand automatisch an. Der Eintrag bleibt 36.000 Blöcke (rund 250 Tage) aktiv und danach dauerhaft in der Kettenhistorie sichtbar. Ein erneutes Verankern verlängert ihn.

Wie beweise ich das später einem Dritten?

Übergeben Sie die Datei und den heruntergeladenen Nachweis (JSON). Der Dritte berechnet den Hash der Datei, vergleicht ihn mit dem Nachweis und schaut den Eintrag im Doichain-Explorer nach. Beides geht ohne Verifile.

Was ist die Doichain?

Eine öffentliche Blockchain der Bitcoin-Familie, die per Merged Mining von Bitcoins Rechenleistung gesichert wird. Sie ist auf fälschungssichere Nachweise ausgelegt, personenbezogene Daten gehören nie auf die Kette.
